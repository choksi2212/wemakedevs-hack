# GRAPH.PROFILE — live receipt (falkordb 6.0.0, sever_demo tenant)

Query (canonical attack-path lookup, literals substituted for PROFILE which
does not bind parameters):

    MATCH (o {objectid: "S-1-5-21-...-2110"}), (t {objectid: "S-1-5-21-...-512"})
    WITH shortestPath((o)-[:MEMBER_OF|GENERIC_ALL|...|AZKVContributor*..12]->(t)) AS p
    RETURN p

Note: range indexes on `objectid` are created per label at load
(`sever/core/falkor_port.py::INDEXED_LABELS`); the canonical query binds
endpoints without a label so the planner chooses All-Node-Scan — still
sub-millisecond at this estate size, and the label indexes serve larger
estates and label-qualified lookups.
